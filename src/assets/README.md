The authentik icons are unmodified official SVG assets from the
[authentik press kit](https://goauthentik.io/press/):

- `authentik-icon.svg`: https://goauthentik.io/img/press-kit/icon-color.svg
- `authentik-icon-white.svg`: https://goauthentik.io/img/press-kit/icon-white.svg

The color icon is used on light backgrounds and the white icon on dark
backgrounds. Assets are bundled locally; displaying the sign-in button does
not contact authentik or any third-party server.
